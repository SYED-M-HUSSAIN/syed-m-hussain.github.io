# Portfolio Images Needed

Please add the following images to the `/images/` directory for your portfolio projects:

## Required Images

1. **openrobotics-lab-thumbnail.png**
   - Screenshot of the OpenRobotics Lab platform homepage
   - Recommended size: 800x500px
   - Should show the main interface with navigation and resources

2. **rag-search-architecture.png**
   - Architecture diagram of the RAG pipeline
   - Should include: Vector DB, LLMs, LangChain components
   - Could be a flowchart or system architecture diagram

3. **mlops-pipeline-diagram.png**
   - MLOps pipeline visualization
   - Should show: CI/CD flow, model versioning, monitoring components
   - Could include Docker, MLflow, Azure services logos

4. **ai-agent-workflow.png**
   - Workflow diagram of the autonomous AI agent
   - Should illustrate: Multi-agent communication, decision flow
   - Could show CoT/ToT reasoning process

5. **document-intelligence-demo.png**
   - Screenshot or demo of document processing
   - Could show: Before/after document analysis, extracted entities
   - Or a visual showing multiple document types being processed

## Image Guidelines

- **Format:** PNG or JPG
- **Resolution:** At least 800x500px for thumbnails
- **File size:** Optimize for web (under 500KB per image)
- **Style:** Professional, clean, consistent across all projects

## Alternative Options

If you don't have specific project screenshots, you could use:
- Architecture diagrams created with tools like draw.io or Lucidchart
- Code screenshots with syntax highlighting
- Terminal/console output showing the system in action
- Flowcharts explaining the process
- Tech stack visualizations
